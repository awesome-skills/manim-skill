# 动态字体与本轮取舍

新增成功读取三个仓库 README，累计 55 个；`encd8/kinetic-typography-javascript` 的 README.md 返回 404，未计入。来源与内容指纹见 [JSON](kinetic-type-2026-10-29.json)。

- [Codrops RepetitiveTypography](https://github.com/codrops/RepetitiveTypography)：README 标注 MIT，深入阅读 `src/js/index.js`，blob `3c4d6ca70e5ca1112d73d683ee19633f1e17a2e1`。使用成组字形错开、复制行和命名时间段，照片在后续阶段加入。浏览器实际打开 demo，检查完成后的重复网格与 hover 后的标题切换；未完整评价开场节奏。可借鉴角色分组与分阶段替换，不把其高密度重复字幕直接用于中文讲解。未复制代码、摄影素材或字体。
- [Pablo Stanley Typexperiments](https://github.com/pablostanley/typexperiments)：README 将测量、布局、字形映射、动画和渲染分开。对文字变宽/换行时保持字符身份有启发，但本轮未检查源码、许可证或性能，不能采信 README 的性能数值为本项目结果。
- [Synfig import labels](https://github.com/berteh/synfig-import-labels)：README 描述按起止时间导入字幕和模板，声明 GPL v2 或后续版本。适合研究有音频的 cue；当前静音 Manim 场景不引入该插件，也不复制模板。

本轮没有新增一个字体特效库。独立光圈试用表明当前更有价值的缺口是可见的因果关系和比较基准，因此将生成规范修订集中于该证据，而非为了融合而加入重复字形、涡旋或爆炸效果。
