# 向量相加：结尾需要给出新信息

保留原有的同起点、平移 b、出现合向量三段连续动作。原结尾 `a + b = a + b` 只重复了符号，新版在开场明确 `a = (3, 1)`、`b = (1, 2)`，结尾用相同颜色得到 `(3, 1) + (1, 2) = (4, 3)`。

标题和字幕字号增大，字幕缩短；公式下移，与网格和底部说明分开。数字直接淡入，不把字母形状变形成坐标。端点、投影线和文字统一由输入坐标计算，避免相互漂移。未新增依赖，也未改变相加关系。
