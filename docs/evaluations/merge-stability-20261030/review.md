# 合并排序：让稳定性在画面中可见

旧示例的数值全不相同，无法展示稳定合并的相等分支。新版输入为左侧 2、5、8，右侧 3、5、9，约定原始序列中左段在右段之前。

- 每张卡片保留来源颜色及 L/R 标记，移动整张卡片。
- 相等时明确显示取左规则，停留 1.4 秒后移动左侧 5。
- 移除装饰性小字，放大来源标签及当前头部标记；相同决策字幕保持静止。
- 最终两个 5 保持 L、R 顺序。空序列阶段改为剩余元素说明。
